# Проект автоматизации тестирования Stellar Burgers
Проект представляет собой набор автотестов для проверки функциональности веб-приложения Stellar Burgers (https://stellarburgers.nomoreparties.site/). Тесты охватывают регистрацию, авторизацию, переходы между разделами, выход из аккаунта и работу конструктора бургеров.

## 1. Основа для написания автотестов
Для написания автотестов используется фреймворк pytest, который обеспечивает удобную структуру тестов, поддержку фикстур и гибкие возможности запуска.

## 2. Установить зависимости
Перед запуском тестов необходимо установить все зависимости, указанные в файле requirements.txt. Выполните следующую команду в вашей командной строке:

```bash
pip install -r requirements.txt
```

## 3. Команда для запуска
Для запуска всех тестов используйте следующую команду в корневой директории проекта:

```bash
pytest 
```
